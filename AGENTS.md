# Instruções para o repositório do Coach GTM

Este repositório distribui o pacote de instalação. Não é o registo GTM de um empresário.

- Se o pedido for instalar ou começar o GTM, lê `SETUP.md` e prepara um espaço de trabalho separado. Depois lê explicitamente a skill principal instalada e começa na mesma conversa.
- Se o pedido for manter este pacote, respeita `docs/FIDELIDADE.md`: os três materiais do Escalar definem o racional, a ordem e as saídas. As skills suplementares ficam subordinadas à principal.
- Escreve em português de Portugal, salvo indicação do utilizador.
- Mantém uma única versão canónica das skills em `skills/`. A ponte de Claude limita-se a encaminhar para a versão instalada.
- Antes de publicar alterações, executa os testes e `scripts/verificar_pacote.py`. Não publiques dados, respostas ou materiais empresariais de participantes.
